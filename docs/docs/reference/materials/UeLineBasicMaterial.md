A material used for rendering lines with a flat color, without lighting calculations.
Provides a simple colored line shader.

> Inherits from [UeMaterial](/docs/reference/core/UeMaterial)

## Parameters

| Name | Type   | Default | Description                                     |
| ---- | ------ | ------- | ----------------------------------------------- |
| data | Object | `{}`    | Optional data object, supports `color` property |


## Methods

| Method                               | Returns     | Description                                                          |
| ------------------------------------ | ----------- | -------------------------------------------------------------        |
| `setColor(color)`                    | `this`      | Sets the flat color of the line material, White is the default color |
