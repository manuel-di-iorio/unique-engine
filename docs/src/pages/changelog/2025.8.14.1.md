# 2025.8.15.1 - Changelog | Unique Engine

- UeOrbitControls:
  - The method update(mouseX, mouseY): may take the mouse coordinates directly as parameters.
  - Added prop "transforming" which tells if the camera is being orbiting with the mouse (no need for the keyboard for now).
  - Increased default damping factor from _0.1_ to _0.9_.
- UeTexture: 
  - Changed "image" property name to "sprite". The sprite is now accepted as first argument.
  - Added auto incremental "id".
