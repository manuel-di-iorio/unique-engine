UeVector3

A 3D vector class that supports common vector math operations. Used for positions, directions, and geometric calculations in 3D space.

Constructor​

new UeVector3(x = 0, y = 0, z = 0)

Data parameters​

NameTypeDefaultDescription
xnumber0X component
ynumber0Y component
znumber0Z component
