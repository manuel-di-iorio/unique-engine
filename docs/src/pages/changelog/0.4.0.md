# V0.4.0 - Changelog | Unique Engine

- UeMeshStandardMaterial: PBR, Fog (Linear/Exponential), Displacement Maps, Alpha Maps, Flat Shading, Normal Maps (in Object/Tangent Space).

- UeDirectionalLightHelper (debug utility to visualize light position and direction in the scene).

- UeAssimpLoader: added tangents/bitangents to imported geometries (required for normal maps in the shader).
