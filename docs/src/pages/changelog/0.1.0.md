# 0.1.0 - Changelog | Unique Engine

- UePerspectiveCamera:
  - Removed autoUse param and use() method. Camera are now visible on the specified view by default.
  - `aspect` param now takes the size of the speficied view instead of the first one.
  - `view` param defaults to 0 instead of view_current.
  - `far` param now defaults to 2000 instead of 32000 (aligns to ThreeJS).

- Added UeCameraHelper.
- Added frustumCulled and renderer's frustum testing.
- Added UE_VECTOR3_ZERO macro.
- UeMesh: raycast() now first checks the bounding sphere, then if it intersects, also checks the bounding box for more precise results.
- Added raycast() to UeLine. UeLineSegments does inherit this method implicitly.
- Chanded UE_EPSILON from global to macro
- Added some dummy global vectors for temp usage in methods.
- UeVector3: min/max methods renamed to minVec/maxVec for compatibility with GameMaker
