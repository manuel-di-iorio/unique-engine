# 2025.11.20.0 - Changelog | Unique Engine

## New Features
- **Project Management**: Implemented robust project loading and saving functionality.
- **Asset Management**: Enhanced asset handling and versioning.
- **Mesh Instances**: Added `UeInstanceList` for efficient management of mesh instances.
- **UI System**: Integrated focus management directly into `UiRoot` and `UiNode`, removing the separate focus manager.
- **Editor**:- Simplified scene editor input handling.

## Documentation
- **Updated**: `UeObject3D`, `UeTexture`, `UeBufferGeometry`, `UeMaterial`, `UeControls`, `UeOrbitControls`, `UePlane`, `UeAssimpLoader`.
- **New**: `UeInstanceList`
- **API**: Documented `import`, `export`, `fromJSON`, `toJSON` methods across various resources.
