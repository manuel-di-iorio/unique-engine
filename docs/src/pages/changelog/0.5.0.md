# V0.5.0 - Changelog | Unique Engine

- UeControls now inherits from UeEventDispatcher, in order to be able to dispatch and listen to events.

- Added `UePointerLockControls` (FPS/TDS-style controls).

- Added `UeCapsuleGeometry` (in Unique Math, `capsule` functions have been implemented)

- Added simple demo platform game with: random cube generation, player inertia movement and jumps, collision handling between capsule and cubes, object collection for points, coyote time for falls.

- Added `UeIcosahedronGeometry` - creates the classic crystal die (icosahedron with 20 faces)

- **Scene Editor**: in the Material Inspector, you can now select the normal/orm/alpha/displacement textures, as well as the base (albedo/diffuse) texture.
