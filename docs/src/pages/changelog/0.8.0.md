# V0.8.0 - Changelog | Unique Engine

- FEAT: Animation system with hierarchical animation and skinning support (`UeAnimation`, `UeAnimationTrack`, `UeSkeleton`, `UeBone`, plus new properties in `UeMesh` and `UeVertexFormat`). Also supports animations blending.
- FEAT: **Level of Detail (LOD)** management (`UeLod`) with hysteresis support for smooth transitions.
- FEAT: **Deferred Rendering** pipeline (`UeRendererDeferred`) - Support for MRT-based rendering (Experimental).
- FEAT: Optimized `UeMaterial` engine uniforms performance using packed arrays and matrices.
- FEAT: Support for vertex displacement and mesh skinning in standard shaders.
- FEAT: Added `canFreeze` and `matrixAutoUpdate` properties to `UeAssimpLoader` (propagated to the objects).
- PERF: Major optimizations in `UeOrbitControls`, `UeAssimpLoader`, `UePointerLockControls`, Lights, and `UeRenderer` collection/sorting phase.
- FIX: `UeCapsuleGeometry` - Fixed tangents and indices to point outwards (corrected backface culling).
- FIX: Corrected object cloning and improved editor selection/reparenting behavior.
- CHORE: Bumped UniqueMath to v4.1
