# V0.7.0 - Changelog | Unique Engine

- [FEAT] Spotlight (up to 4, with 1 shadow-mapped light) and Hemisphere lights (added `UeSpotLight, UeSpotLightShadow, UeSpotLightHelper, UeHemisphereLight, UeHemisphereLightHelper`).
- [FEAT] UeMouse: added `worldToScreen()` and `screenToWorld()` utilities.
- [FEAT] Particle Engine (added `UeParticleSystem, UeParticleEmitter, UeParticleType` alongside various particle modules).
- [FEAT] Optimized UeRenderer: now it separates objects to render to sort them efficiently. Also the frustum culling is done pre-emptively in the collect phase, based on the shadow/main pass.
