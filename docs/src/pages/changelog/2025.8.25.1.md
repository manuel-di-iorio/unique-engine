# 2025.8.25.1 - Changelog | Unique Engine

- UeOrbitControls:
  - The method update(mouseX, mouseY): may take the mouse coordinates directly as parameters.
  - Added prop "transforming" which tells if the camera is being orbiting with the mouse (no need for the keyboard for now).
  - Increased default damping factor from _0.1_ to _0.9_.
- UeTexture: 
  - Changed "image" property name to "sprite". The sprite is now accepted as first argument.
  - Added auto incremental "id".
  - Added "userData" struct.
  - Changed method "__update()" to "update()" (may be used in cases where automatic updates are not possible)
- UeObject3D: Added UeInstanceList core class and "instances" property, to manage the object's instances
- Added UeGame core class, to easily manage a buffer imported with the BufferLoader
- UeMatrix4: 
  - Added scaleXYZ(x,y,z)
  - Fixed multiply() and premultiply() multiplications order
