# V0.3.0 - Changelog | Unique Engine

- Fully changed editor's save/load system and project structure.
- Renamed UeBufferGeometry to UeGeometry and switched the vertices to use flat arrays instead of structs, but on separate variables (position, normal, uv, color, index, etc..).
- Because of the previous change, some UniqueMath's methods have been updated to use flat arrays of vertices instead of structs (eg. UeBox3's computeBoundingBox method).
