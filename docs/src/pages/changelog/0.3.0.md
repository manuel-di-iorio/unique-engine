# 0.3.0 - Changelog | Unique Engine

- Added UeMouse() for mouse utils
- UeRaycast: setFromCamera() now only accepts camera (mouse coords are automatically calculated)
- Optimized models loading times for UeObjLoader and UeAssimpLoader
- UeAssimpLoader: it now directly set the bounding box/sphere, without the need to compute them from vertices
- UeQuaternion: added invert(), conjugate(), length(), rotateTowards(), multiplyQuaternions(), equals(), toArray()
- UeTransform: param `target` of getWorldDirection() now defaults to `new UeVector3()`
- UeBufferGeometry: added export() and import() to quickly save and load only the vbuffer to a file (without anything else).
- Changes to lighting and standard light shader:
  - Directional light is now applied by using pitch/yaw rotations in degrees.
  - The shader will use linear color-space gamma correction. Tone mapping will be implemented later.
  - Point lights got quadratic attenuation for better results. Still 2 lights per each type supported.
  - Added emissive/emissiveMap support.
- Added UeStaticMesh(): just a wrapper around UeMesh() with `matrixAutoUpdate` set to `false`
