# V0.7.0 - Changelog | Unique Engine

- [FEAT] Spotlight (with 1 shadow-mapped light) and Hemisphere lights (added `UeSpotLight, UeSpotLightShadow, UeSpotLightHelper, UeHemisphereLight, UeHemisphereLightHelper`).
- [FEAT] UeMouse: added worldToScreen() and screenToWorld() utilities
- [FEAT] Particle Engine (added `UeParticleSystem, UeParticleEmitter, UeParticle, UeParticlePool, UeParticleRenderer` and various particle modules).
- [FEAT] Optimized UeRenderer: now it separates collected objects to sort them differently. Also the frustum culling is done in the collect phase, based on the main/shadow pass.
